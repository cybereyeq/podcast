How this is built

Eight regulation trackers run nightly (3:00 AM – 5:55 AM) across the CybereyeQ pipeline, each pulling enforcement dates, transposition windows, and consultation closes from primary sources. A nightly aggregator (scripts/build-calendar.sh) merges every upcoming_deadlines array into one JSON, which this page renders.

Discovery-feed candidates (regulations not yet enacted but plausibly heading there) overlay on the heatmap at lower opacity, using the registry's confidence tiers.
